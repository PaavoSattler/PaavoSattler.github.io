# PaavoSattler.github.io

Prepared Quarto project for the personal academic website of **Paavo Sattler**.

The repository is intended to remain **private during development** and become public only when the site is ready for GitHub Pages.

## Main site sections

- Home
- Research
- Publications
- Software
- Collaboration
- About
- privacy-safe web CV
- Privacy / Legal templates

## Prepared infrastructure

- dark-violet visual system
- 4:5 profile-photo placeholder
- responsive homepage layout
- research and software detail pages
- publication/preprint data scaffolding
- JSON-LD Person structured data
- Open Graph/social preview image
- GoatCounter click-event hooks (analytics disabled until launch)
- Google Search Console placeholder
- 404 page
- robots.txt
- render-check GitHub Action
- public-launch workflow template
- arXiv metadata cleanup checklist
- GitHub username migration checklist
- maintenance guide
- pre-launch scan script
- GitHub profile README draft
