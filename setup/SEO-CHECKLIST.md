# SEO and discoverability checklist

## Already prepared

- stable site URL: `https://paavosattler.github.io`
- page descriptions
- Open Graph / social card support
- generic social preview image
- JSON-LD `Person` structured data
- ORCID / Scholar / GitHub / institutional profiles in `sameAs`
- robots.txt
- stable, descriptive research/software URLs
- separate pages for methods and packages

## At launch

- make repository public
- enable GitHub Pages
- verify the rendered canonical URLs
- register the site in Google Search Console
- add the Search Console verification meta tag
- check that the generated sitemap is reachable
- submit/check sitemap in Search Console
- inspect the home page and main software/research pages with Google's URL inspection tool

## External-profile consistency

Use the same preferred name and website URL wherever possible:
- Google Scholar
- ORCID
- GitHub
- TU Dortmund profile
- RWTH Aachen profile
- CV
- R package DESCRIPTION/CITATION metadata
- arXiv metadata where editable

## Content strategy

The main SEO value should come from useful, specific pages rather than keyword stuffing. Keep descriptive pages for:
- directional / one-sided inference
- covariance & correlation structures
- high-dimensional repeated measures
- resampling & randomization-based inference
- CovCorTest
- hdrm
- HypoShrink
