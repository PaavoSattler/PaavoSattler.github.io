# Paavo Sattler

**Researcher in Statistics**  
TU Dortmund University · RWTH Aachen University

I work on statistical methodology for complex multivariate and high-dimensional data, with particular interests in nonparametric inference, structured and directional hypotheses, multiple testing, resampling-based methods, and statistical computing.

## Research interests

- Multivariate & high-dimensional inference
- Nonparametric & resampling-based inference
- Structured, multiple & directional hypotheses
- Covariance & correlation structures
- Statistical computing

## Software

- **[CovCorTest](https://CRAN.R-project.org/package=CovCorTest)** — inference for covariance and correlation matrices and structures
- **hdrm** — high-dimensional repeated-measures inference
- **[HypoShrink](https://github.com/PaavoSattler/HypoShrink)** — simplifying linear hypotheses for efficient quadratic-form-based inference
